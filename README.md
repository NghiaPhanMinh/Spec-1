# Pause the Decision

A buildless p5.js installation. Serve `dist/` with an HTTP server; HTTPS is required for webcam use outside localhost.

Frozen: detailed astronomical dial, DIFFERENCE blend, seven-octave noise, camera dithering, filtered static. Confirmed presence: rewind, two-octave domain-warped pastel flow, hidden message threshold, softened halftone, chime and ticks.

Face detection uses MediaPipe on-device. Gender is never inferred. The visitor explicitly confirms a woman is present, and a visible face gates the transition. Camera-free demo is labelled separately. Audio requires opt-in; an optional local audio upload replaces the synthetic pause voice. No camera or audio uploads, analytics or persistence.

External resources: MediaPipe JS/WASM via jsDelivr and Google's face detection model; Google Fonts. p5.js 1.11.3 is bundled under its LGPL license. MediaPipe reference: https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector/web_js
